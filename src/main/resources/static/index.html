Como funciona
1. Cadastre produtos da Amazon na aba Produtos com o ASIN.
2. Configure canais Telegram em Canais (use Chat ID negativo para grupos).
3. O scheduler roda a cada 30min e compara preço atual com histórico.
4. Quando detecta desconto ≥ alvo, gera mensagem com IA e envia ao canal.
